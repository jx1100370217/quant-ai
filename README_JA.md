### 🔥 人気セクター精選
**純流入最大セクター**の構成銘柄から、定量プレスクリーニング後に16人のマスターが総合採点し、最適な買い候補を選出。

### 🏆 マスター総合精選（全A株）
**全A株5,500銘柄以上**の純流入Top30から、定量プレスクリーニング後に16人のマスターが分析。単一セクターに限定されず、市場全体で最もマスターに支持された銘柄を選出。

### 📅 週次銘柄アドバイザー（V14 Research Baseline）
全A株から深V反発候補をスキャンし、反転スコアでTop候補を選んでLLM週次レポートを生成する2段階の反転戦略です。

```
全A株約5,500銘柄（東方財富 clist、100銘柄/ページ、売買代金順）
                    ↓
        停牌 / ST / 退市リスク銘柄を除外
                    ↓
        ハード条件：5日安値からの反発 ≥ 3.5%
                    ↓
        V7 深V反転スコア（40点以上）
          5日反発 / 2日モメンタム / 7日下落深度
          出来高比率 / 出来高確認 / ATR価格比 / RSI6
                    ↓
        反転スコア順に Top 1-5 を選定
                    ↓
        順位別ウェイト：35/25/20/12/8%（未使用枠は現金で保持）
                    ↓
        目標 +5%；単一銘柄 -6% ハードストップ
        週内ポートフォリオ損益 ≤ -4% → 翌日全撤退シグナル
                    ↓
        LLM買い理由 / リスク注記 / Telegram通知
```

### 🌐 マルチアセット週次レコメンド

- **A株個別銘柄**：大型・中型株の深V反転候補から最大5銘柄を選び、候補不足分は現金として保持します。
- **具体的な公募投資信託**：「財通成長優選混合C（021528）」を含むアクティブ株式型Cクラス34商品を、1週/1か月/3か月リターン、20/60日トレンド、プラス週比率、ボラティリティ、ドローダウン、申込状態で比較し、最大5商品を提示します。
- **主要暗号資産**：BTC、ETH、SOLなど流動性の高いUSDT現物16銘柄を、7/30日モメンタム、20/60日トレンド、出来高、ボラティリティ、ドローダウンで比較し、リスク調整後の上位最大3銘柄を提示します。

3つの資産クラスは、戦略バージョン、キャッシュ、追記専用の推薦監査履歴をそれぞれ独立して管理します。投資信託と暗号資産のランキングはLLMに依存せず、公開市場データから再計算できます。
投資信託の基準価額履歴は東方財富/天天基金の公開データ、暗号資産の日足はBinance Spotの公開市場データを使用します。キャッシュデータは、明示されたフォールバックとしてのみ利用します。

### 🧭 口座連携不要のリサーチ端末

フロントエンドは実際の証券口座や保有残高を読み取り・表示しません。画面上の比率はすべて研究用モデルポートフォリオの配分であり、実口座の状態ではありません。

## 🚀 クイックスタート

### 必要環境
- Python 3.10+
- Node.js 18+
- Anthropic API Key または Claude Code Max OAuth Token

### 1. クローン & インストール

```bash
git clone https://github.com/jx1100370217/quant-ai.git
cd quant-ai
bash scripts/setup.sh
```

### 2. LLM認証の設定

```bash
cp backend/.env.example backend/.env
```

`backend/.env` を編集し、以下のいずれかを設定：

```bash
# 方法1：標準 Anthropic API Key
ANTHROPIC_API_KEY=sk-ant-xxxxxxxx

# 方法2：Claude Code Max OAuth Token（無料枠が大きい）
ANTHROPIC_OAUTH_TOKEN=sk-ant-oat01-xxxxxxxx
```

### 3. 起動

```bash
bash scripts/start.sh
```

| サービス | URL |
|----------|-----|
| フロントエンド | http://localhost:3000 |
| バックエンドAPI | http://localhost:8000 |
| APIドキュメント | http://localhost:8000/docs |
