# QuantAI 周推荐研究协议

本协议用于约束策略研究结论，目标是减少幸存者偏差、参数窥探和理想化成交造成的虚假提升。

## 1. 数据等级

| 等级 | 数据 | 可以支持的结论 |
|---|---|---|
| D0 | `cache/kline_5y_portable.pkl` 当前800只成分回溯 | 代码回归、相对敏感性分析；不得宣传绝对收益 |
| D1 | `backend/cache/universe/history/YYYY-MM-DD/` 实时完整快照 | 从快照日期起的 point-in-time 回测与复盘 |
| D2 | `backend/cache/weekly_reports/recommendation-ledger.jsonl` 前瞻推荐流水 | 未改写的模拟盘/实盘外推检验 |

只有覆盖率不少于90%、分页无失败的实时 universe 批次会写入 D1。容错缓存和部分成功批次仍可供应用展示，但不能成为 point-in-time 研究样本。

## 2. 时间切分

- 2020-12 至 2023-12：开发期，已经参与策略研究。
- 2024-01 至 2026-04：复用验证期，曾参与参数比较，因此不是纯样本外。
- 未来 D1/D2 数据：前瞻期；参数冻结后才可作为真正外推证据。

`scripts/backtest_engine.py` 默认只输出冻结生产口径的全样本、开发期、复用验证期和零成本诊断。历史参数网格必须显式使用 `--research-grid`，且输出仍属于研究期结果。

## 3. 冻结执行假设

- 双边佣金：3 bp。
- 双边滑点：10 bp。
- 卖出印花税：2023-08-28 前10 bp，之后5 bp。
- 开盘接近涨停：不假设可以买入，仓位留在现金。
- 开盘接近跌停、停牌或一字跌停：不假设可以卖出，向后尝试最多5个交易日。
- 买入日触发风险线：遵守 A 股 T+1，下一可成交日退出。
- 周五收盘触发组合风险线：允许跨周到下一可成交日开盘退出。

日线无法恢复封单队列、逐笔成交和真实市场冲击，上述规则仍是近似。若延迟窗口后仍无法退出，结果必须单独报告为 `unresolved_exits`。

## 4. 发布门槛

策略版本升级前至少同时满足：

1. 自动测试与前端构建通过；
2. 冻结口径的风险指标没有明显恶化；
3. 报告交易成本拖累、未成交买入和延迟/未解决退出；
4. 不把开发期或复用验证期称为“未触碰样本外”；
5. 参数变更必须先登记版本，再等待新的 D1/D2 前瞻数据验证。
